Few-shot Personalization for Recommendation Systems

A Meta-Learning Approach to the Cold-Start Problem

Ilyes Ouldsaada • MovieLens-100K Experiment

The Challenge

Recommendation systems struggle with the cold-start problem: generating accurate predictions for new users with minimal interaction history[cite: 10]. This project frames user adaptation as a few-shot learning task, where models must rapidly adapt using only a small "support set" of 5 to 20 ratings[cite: 9, 10].

Methodology

  • Representation Learning: A custom SimCLR-inspired pipeline learns robust, continuous movie embeddings from unstructured metadata using stochastic masking and noise[cite: 9, 10].
  • Meta-Learning Regressors: Compares optimization-based approaches (Reptile) against metric-based (Matching Networks) to enable rapid adaptation to unseen user profiles[cite: 9, 10].
  • Evaluation: Models are evaluated on user-disjoint train/test splits using Normalized Discounted Cumulative Gain (NDCG) to measure ranking quality[cite: 9, 10].
